## What to build

1. **Opening at a path.** One function in the layout or file browser state that takes a served root and a path under it (a folder or a file) and opens the Files view with every ancestor folder open, the path selected and scrolled into view. It focuses the Files tab of the current page when one exists and opens one there otherwise. A path that does not exist selects its nearest existing ancestor and says so in the view's outcome line. A hub-relative path resolves to the hub root.
2. **The controls.** A "Show in Files" control (a catalog string and a glyph from `config/glyphs.yml`, added with its Lucide icon in `config/icons.yml` if none fits) on the project card and the project view (the project's folder), and on every collection card whose schema field holds a hub-relative path (the fields listed above, told apart from web addresses by the value itself). On the cards it is one of the card's controls, under Q34's `views/shared/CardActions.svelte`.
3. **Loading.** When the folders on the way are not read yet, the Files view reads them in order before selecting, and the row is scrolled into view once drawn.
