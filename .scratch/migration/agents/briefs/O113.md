## What is on the tree (read on main at 4f76fdcce)

- `src/lib/server/sessions/record.ts:29` caps `timeline` at 200 events.
- Places that name the view: `config/defaults/layout.yml:64`; `src/lib/views/shared/card/card.ts:59` (`SESSION_VIEWS`); `src/lib/views/sessions/session-list/SessionList.svelte:32,241`; `src/lib/state/workbench/selection.svelte.ts:6,11`; `docs/HELP.md:246,249`; `docs/palette.md:44` (generated by `npm run docs:palette`).

- The Files view's own Timeline section (`src/lib/views/sources/files/sections/Timeline.svelte`, `state/sources/explorer/sections/timeline*`, `showTimeline`, `menu_timeline`, `TAB_TIMELINE`, `ROW_TIMELINE`) is a different thing and is not touched.

The orchestrator changes that data once, at landing. No code reads, drops or converts a saved `timeline` tab; until the data is changed such a tab draws as an unknown view (`registry.ts:245`).
- `docs/adr` does not exist; no ADR touches the step.

## What to build

1. `session-sections.ts`: `SECTIONS` becomes `details, changes, timeline, agents`.
2. New `src/lib/views/sessions/session-detail/TimelineTurns.svelte`: the body of the section, taking the session record. It holds what `Timeline.svelte` draws of turns and events, with the same tags, tones, tooltips and row words, and the empty message `sessions.tl_empty`. It has no Pane, no bar, no picker, no registration and no record-less state, since the Session view asks for a session itself. Its scroll rule stays: it starts at the newest event when mounted or when the session changes, and afterwards follows a push only while the reader is at the foot.
3. The turns scroll inside a box with `max-height: 40vh`, so the Agents section under it stays reachable, in the view's size: words at `--fs-sm` (inherited from `.session`), clocks at `--fs-xs`. Heading weight, indent, row height and border as today. The rice face rule goes, since `.session` sets it.
4. `SessionDetail.svelte`: a `timeline` branch drawn through `SessionSection` with `label={t('sessions.section_timeline')}`, `count` the number of turns, `rows={[]}`, the body wrapped in `<li role="none">`. The `{:else}` for Agents becomes an explicit branch if the chain then reads better. The toolbar's Timeline button goes; the Transcript button stays. The head comments state four sections and name the group order without Timeline.
5. Delete `src/lib/views/sessions/timeline/`.
6. `config/text/views/sessions/timeline.yml`: its head line says the section owns it; add `section_timeline: Timeline`; remove `view_timeline`, `timeline_bar`, `timeline_glyph`. A key nothing reads after the change goes too.
7. The glyph `timing` stays: `VenueCard.svelte:225` and `Ribbon.svelte:53` use it.
8. `config/defaults/layout.yml`: the `timeline` line goes.
9. `card.ts`: `timeline` leaves `SESSION_VIEWS`.
10. `SessionList.svelte`: a pick in a list limited to a folder opens the Transcript and the Session view of the session in the documents, the Session view by `openView('session-detail', pinned, page, { document: true })` in place of the Timeline line. Its head comment says so.
11. `selection.svelte.ts` comments, `docs/HELP.md` (the `session-detail` row reads "One session: Details, Changes, Timeline, Agents."; the `timeline` row goes; line 343 lists the four sections), `docs/palette.md` by running `npm run docs:palette`. Every other sentence the change makes false is found by grep and fixed.

No code handles a saved `timeline` tab.

## Cases

A builder runs no page (`agents/spec.md`, What every package obeys). Each case below is checked by reading and, where the rules file calls for one, a case-run program; its proof in a page is the orchestrator's look at landing, which takes every case below on a scratch server.

- A session with events, in the Session view: sections read Details, Changes, Timeline, Agents, top to bottom, and Timeline's head counts the turns the section draws.
- The section draws what the Timeline view drew: the same turns, tags, tones, clocks and tooltips, with a turn as its length, a bust as its size, a path as its last name with the whole path in the tooltip, and a prompt in its own words.
- A session past the 200-event cap: the head counts the turns of the events held, a group before the first prompt among them, and the first group reads `sessions.tl_before`.
- A session with no events: the head counts 0 and the body says `sessions.tl_empty`.
- Close and reopen the section: the closed state is kept in the tab, and on reopening the box stands at the newest event.
- Another session picked while the section is open: the box stands at the newest event of that session.
- A drag of the head, and Alt+Up and Alt+Down on it, move the section among the others, and the order survives a reload. A section moved keeps the box usable: at the foot it still follows a push.
- A push while the reader has scrolled up in the box (a line appended to a transcript under the scratch HOME): the box does not move. At the foot: it follows.
- More events than the box holds: the box scrolls, and the Agents head stays reachable with the pane's own scroll.
- Rows at `--fs-sm` and clocks at `--fs-xs`, by `getComputedStyle`.
- A pinned Session tab's toolbar holds Transcript alone.
- A pick in a folder-limited list opens Transcript and Session in the documents, and no tab of `timeline`.
- The palette and the view menus offer no Timeline view, and `grep -rnE "pin\('timeline'\)|openView\('timeline'|id: 'timeline'|view: timeline" src config/defaults` finds nothing.
- A fresh layout's Sessions page has no Timeline tab.
- A saved tab of `timeline` draws as an unknown view and nothing converts it.

## Decisions taken in this brief (each reversible, none silent)

1. The turns scroll in a box of at most 40vh, which keeps the Timeline view's scroll rule and leaves Agents reachable.
2. Clocks at `--fs-xs`, words at the view's `--fs-sm`, so the section sits with the type sizes of the Session view.
3. The head's count is the turns the section draws, the number every other head gives for its own rows, which on a session past the event cap is less than the session list's prompt count.
4. A folder-limited pick opens the Session view where it opened the Timeline view, so the turns stay one press away there.
