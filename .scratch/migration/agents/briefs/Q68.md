## What is on the tree (read on main at 8b82940d)

- `tests/server/watch/git.test.ts:655-680`, "reads a root added to the workspaces file while it is running": it starts `watchGit` with `workspacesFile`, waits up to `WAIT` (6000 ms, `:38`) for the first root's state, writes the workspaces file with a new root, and waits up to `WAIT` for the added root's state; `:679` then reads `latest(client.got)[added].branch`.
- It failed twice under load: once in a whole node run beside the browser suite (`AssertionError` at `:679`, the added root absent after the wait) and once in a reviewer's whole run. Alone it passed 22 of 22 in three runs on main, and in the whole runs without the browser suite.
- `src/lib/server/watch/git.ts:321-334`, `watchWorkspaces`: one `fs.watch` on the file's folder, filtered by the file's name, calling `readRoots()` and `follow()` on an event; `:368` starts it. Nothing reads the workspaces file again if that event is never delivered.

## What to do

1. Find the cause, and prove it: make it happen on demand (for instance by writing the file right after the watch starts, or with the host loaded), and quote the failing run.
2. Fix the cause in the watcher or in the test, whichever holds it.
