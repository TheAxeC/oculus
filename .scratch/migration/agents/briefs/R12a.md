## What is on the tree (read 2026-09-14 at 12:35 on main at 2b09638c)

Each edge below names its landing note, the file as read, and what the fix is. A fix stays inside the edge; a fix that would need a new user-visible shape is a stop, reported and not built.

1. **O6, no signal handling.** `src/server.ts` (29 lines) creates the server context, attaches the socket and listens; `grep -n 'SIGINT\|SIGTERM\|process.on'` finds nothing. Fix: `SIGINT` and `SIGTERM` close the context (its watchers, the pty channel's timer, the socket's clients) and the http server, then exit 0; a second signal within the close exits at once. A test over the close path with the signal handler called directly (no real signal), asserting the context's close ran once.
2. **O6, an unrelated `.yml` beside a registry triggers a rebuild.** `src/lib/server/watch/portfolio.ts` line 58 counts an event when the filename ends in `.yml` under a watched root. Fix: an event counts when the path is one the config names (a registry file, a feed file, a collection file, a manifest `project.yml`, a file under `config/`), read from the same config the watcher already holds; any other `.yml` is ignored. A test with a temporary hub: writing `registries/venues.yml` rebuilds, writing `registries/notes.yml` does not.
3. **O13, a missed first event and a periodic rescan.** `src/lib/server/watch/sessions.ts` rescans on quiet after an event (line 34, the quiet window) and re-checks liveness; `fs.watch` can miss an event right after a watch opens. Fix: one slow clock (minutes, a named constant with its reason) triggers a full rescan of the session stores whether or not an event came, cleared on close. A test with fake timers: the clock fires the rescan; close stops it.
4. **O13, the git watcher's two stderr lines per start for a workspace that no longer exists.** `src/lib/server/watch/git.ts` lines 110 and 157 log a read failure and a watch failure per root. Fix: a root that does not exist is skipped silently at start (its absence is the sessions store's business, not a failure), logged once only if it existed and vanished. A test over a payload naming a missing root: nothing on stderr.
5. **O17, `list-sessions` every five seconds with no control client.** `src/lib/server/pty/channel.ts` line 49 `POLL_MS = 5000`, the timer at 277 while no client is attached. Fix: two named intervals, the five seconds while a control client is open and a slow one (a minute) while none is; the switch on attach and detach. A test with fake timers over both states.
6. **O17, an `oculus-` session made by hand with another id shape is listed but cannot be stopped or resized.** `src/lib/server/pty/sessions.ts` line 17 `PREFIX = 'oculus-'`; the id after the prefix is what the stop and resize paths take. Fix: a session whose name after the prefix is not an id oculus mints is listed with a flag the client can read (`foreign: true` in the wire shape, said in the report as the one wire addition, a boolean beside what is there) and the stop and resize paths refuse it with a reason rather than failing silently. A test over a hand-made name.
7. **O19b, no cap on the turns a first transcript read sends; `forget` is called by nothing.** `src/lib/state/transcript.svelte.ts` `turnsFor(id)` asks the server for the whole file the first time; the server route `src/routes/api/transcript/` (read it) answers with every turn. Fix: the first read is capped at the last N turns (a named constant, 200, with its reason) and carries the offset so the client's existing append path continues from there; the client's `forget(id)` is called when the last instance showing that session closes (the shell's instance close is not this package's file: the store exposes what the shell needs, and the call site is R12b's item if it is in a view, or noted for the orchestrator if it is in the shell). Tests over the cap and the offset.
8. **O20, `refreshGit(root)` re-reads only a root the watcher already watches.** `src/lib/server/watch/git.ts`: a write to the hub when the hub is not a session workspace shows late. Fix: the hub root itself is always watched, whether or not a session names it, since the hub's own git state is what the deposit and the pin controls read. A test: a payload naming no workspace still watches the hub root.
9. **O20, the push control reads "no upstream" until the branch listing answers.** `src/lib/server/git.ts` or `git-routes.ts` (read where the upstream is computed). Fix: the state carries `pending` until the first listing answers, and the client's existing pending handling draws it (the client side is R12b's if a view draws the words; the server sends the fact). Say in the report which side changed.
10. **O21, `switchBranch` copies a branch's files over `code/` and deletes nothing a branch removed; `snapshot` leaves a `master` default.** `src/lib/server/deposit-git.ts` (`setHeadMain` at 156, the force push at 227). Fix: the switch removes the files the old branch had and the new one lacks (a listing of both trees, the difference deleted, nothing outside `code/`); `snapshot` points HEAD at `main` for a repository whose default was `master`. Tests over a temporary repository for both.
11. **O21, `gh` is never run by a test.** `tests/server/deposit.test.ts` records `gh` calls (line 132) and asserts the count; no test drives the create, push and About paths with a recorded `gh`. Fix: a recorded-`gh` test that plays back a fixed answer for each of the three commands and asserts what the deposit code does with it.
12. **O26, the log search runs a 55-second remote command on a cold path; `src/routes/api/hpc/post.ts` is the one route written as an indirection.** `src/lib/server/hpc/actions.ts` line 41 `runner(host, remote, 55000)`. Fix: the remote command's inner search is bounded by a shorter `timeout` (the 20 s inside it stays; the outer 55 s becomes 25 s with the reason), and `post.ts` becomes a route module like the others (`src/routes/api/hook/+server.ts`'s shape: the POST calling one server function), the test target stays injectable through the locals. Tests follow.
13. **O26, no Playwright spec over a stubbed `hpc` channel.** Not this package's (the browser suite is R12d's); named here so it is not lost.
