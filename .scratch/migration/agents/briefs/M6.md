### 1. The rule that places and builds an entry (`data/helpers/files/collection-text.ts`, new, layer 1)

2. **Where the new entry is built.** (a) On the server, a read route answering the file's text with the entry placed. Pro: the server's rendering and location are reused as they are. Con: the text it answers is the disk's, so a tab holding the reader's unsaved edit gets it replaced, and the second press of Add cannot see the first stub. Con: the text lives only in the editor model until the tab's next change reaches the draft, a snippet's choice syntax would have to escape every YAML value, and the store (G28) does not see it as the draft's insertion. Taken: (b). The lazy option is (a), which reuses code and loses typing.
