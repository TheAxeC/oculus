## What to build

1. **Cmd+Shift+P and F1.** Cmd+Shift+P (Ctrl+Shift+P off macOS) and F1 open the palette in its command mode, exactly as `:` opens it today (the query `:`, the colon commands listed). With the palette open in another mode, either key switches it to the command mode; with it open in the command mode, either key closes it, as Cmd+K closes the open palette. Both work with the keyboard anywhere the page has it: a view, a text field, the source editor and a diff editor, a terminal (F1, and off macOS Ctrl+Shift+P, kept from the program in `grid-keys.ts` as the find keys are), a float and a float's own window. The modifier is read mac-aware as `appKey` reads it: Cmd on macOS, Ctrl elsewhere; on macOS Ctrl+P and Ctrl+Shift+P are left to the editor, the terminal and the field. With the key sheet open they do what Cmd+K does there (nothing); with a confirmation or the update tray open, what Cmd+K does.

2. **F1 taken from Monaco.** Inside the source editor and the diff editor, F1 reaches the shell as Cmd+K does: it is added to `freedKeys`, so Monaco's own command palette no longer opens on F1. Cmd+P and Cmd+Shift+P reach the shell from inside Monaco too; if Monaco binds either, it is freed the same way. The "Command Palette" item of the editor's right-click menu opens oculus's command mode (decision 9), never Monaco's palette.

3. **Cmd+P, the file mode.** Cmd+P (Ctrl+P off macOS) opens the palette in a new file mode, which finds files by name across the served roots, as VS Code's Cmd+P does:
   - The mode has no typed prefix: the input starts empty and says, as its placeholder, that it searches files by name. Typing `:` as the first character switches to the command mode and `#` to the symbols, as from Cmd+K. Cmd+P with the palette open in another mode switches it to the file mode; with it open in the file mode, Cmd+P closes it.
   - The names are the files of the served roots: the same roots as the Search view, the same `SKIP_GLOBS`, ripgrep's `.gitignore` rules, hidden files and folders listed (`--hidden`; decision 5), the private folders left out (decision 6), no size limit, links not followed. A file under two served roots (a root inside another) is listed once, under the root whose folder is deepest (decision 7). They are asked of the server once per opening of the mode, through the search route (decision 1), by the `search` store, and matched on the page as the query is typed, with the palette's fuzzy matcher (`fuzzyMatches`, fuzzysort), over the path under its root with the file name weighted first as VS Code's quick open weights it (decision 2).
   - The matcher prepares the names once per answer, and at most 200 rows are drawn for a query (decision 8); a keystroke over 100,000 names is matched in under 50 ms on this machine, measured by a probe the report quotes.
   - Each row is a `PaletteRow` with the file's icon as the Files view draws it (`PaletteRow.svelte` gains the icon, so the file mode draws no row of its own beside it), the file name with its matched letters marked, and after it the folder under the root and the root's key. Names with spaces and non-ASCII letters are listed and opened. With nothing typed, the rows are the file tabs open on the page (source, File view, Document, Markdown preview), the active tab of the focused pane first, then each pane's tabs in that pane's recent order.
   - Enter, or a press on a row, opens the file in the view the Files view would choose for it (`tabForKind`: source, Document or File view by its kind), in the pane the palette was opened over, as a kept tab, never the preview tab (decision 4); the palette closes and the keyboard goes into the opened tab's content (the editor for a source tab). `tabForKind` moves from `views/shared/explorer/opening.ts` into `state/sources/explorer/file-type.ts`, its importers following, and the `explorer` store gains the call that reads the kind and opens the tab, which the palette uses; no allow list of `boundaries.test.ts` changes. The file mode is opened by a handler option of its own; `openPalette(prefill)` keeps its signature.
   - While the names are being read, the list says so; a refusal or a timeout of the server is said in the palette, which stays open.
   - The answer is capped at `search.max_names` names in all, a new key of `config/behavior.yml` beside `max_hits`, default 100000, read through `searchSettings`, with its help in `config/catalogs/options.yml` (decision 1); a list cut there says that it was cut and at how many.

4. **The server's names.** The search route answers `GET /api/search?list=names`, with `root=<key>` naming one served root or, absent, all of them (decision 1), with `{ ok: true, roots: [{ root, paths, error? }], cut }`: `paths` the paths under that root that ripgrep's `--files` lists, `error` `timed_out` or `failed` for a root whose run did not finish, `cut` true when the cap was reached. Each root runs through `runRipgrep` with one argument vector (`--files`, `--hidden`, `SKIP_GLOBS`, a `!` glob for each private folder under the root), the route's timeout and a bounded read; the roots run at once, so the answer waits at most one timeout. The child is ended once the cap is reached. A root key that is not served or an empty key is refused before any process starts (G2), and the write token as for a search (G1). A request without `list` is a search, answered as today; `list` empty, repeated or any value but `names` is answered `400 { error: 'list' }`. No name of a file outside the served roots is ever answered.

5. **Cmd+K as it is.** Cmd+K and Ctrl+K open the palette with nothing typed and close it, as today; `:` and `#` as today; Cmd+T in the app as today. The pane strip's Open File... is unchanged.

6. **The text.** The key sheet (`config/text/app.yml:13`) lists Cmd+P, Cmd+Shift+P and F1. `HELP.md`'s key table gains their rows beside Cmd-K. `docs/window.md`'s "The palette" section says what Cmd+Shift+P, F1 and Cmd+P open and how the file mode lists, matches and opens files. `DESIGN.md:142` names the names request with its reason (decision 1). `editor-status.svelte.ts:14-15` names F1 beside the Cmd+K chords. Each head comment listed under "What is on the tree" is made true, or left and marked still true in the report. Every new user-visible string is a catalog key in `config/text/`, read by the code (G24).

7. **Size.** `Palette.svelte` stays at or under 520 lines and every source file at or under 880: the file mode's rows go in a component of their own under `src/lib/shell/keys/rows/`, as the other modes' rows do, and code moves out of `Palette.svelte` and `Workbench.svelte` (517 lines) before anything is added to either. No folder passes 10 items.

The names come from the existing search route as `GET /api/search?list=names[&root=<key>]`, answered `{ ok, roots: [{ root, paths, error? }], cut }`, asked once per opening of the file mode, capped at `search.max_names` (default 100000) in `config/behavior.yml` beside `max_hits` (the orchestrator, automode, Z744). A route folder of its own would make `src/routes/api/(files)/` hold 11 items; the search route already holds the served roots, the token, the timeout and ripgrep's one call site. Asking once per opening and matching on the page keeps typing free of requests: the served roots' names are about 11,000 paths and well under a megabyte (measured above). The cap bounds a machine whose roots hold far more; as a config key it follows `max_hits`, where a constant beside it would be the one search bound a reader cannot set.
2. The match weights the file name first, then the folder, as VS Code's quick open does, with the palette's existing fuzzy matcher (fuzzysort 4.0.2, already a dependency) and no second matcher.
3. The file mode has no typed prefix, as VS Code's Cmd+P has none; its placeholder names it. `:` and `#` typed first switch modes as they do from Cmd+K.
4. A key pressed while the palette is open in its own mode closes it, and in another mode switches to its own, as Cmd+K's close and VS Code's re-press do. A file opened from the file mode is a kept tab with the keyboard in its content, as VS Code's quick open opens one by default (Z744).
5. Hidden files and folders are listed (Z744): the ledgers under `.scratch/`, `.agents/plan.yaml` and every `.oculus/project.yml` are files Axel opens, 1,708 of them in the hub; `.gitignore` still leaves out what a repository ignores (the worktrees among them). Ripgrep's default, which hides them, is the lazy option.
6. The private folders (`privateFolders`) are left out of the names (Z744): a name typed in the palette never surfaces a secret file's name; the Files view still reaches them.
7. A file under two served roots is listed once, under the deepest root (Z744), so the engine root's files are not listed twice.
8. At most 200 rows are drawn for a query, over names prepared once per answer (Z744), so a keystroke stays fast over the cap.
9. The editor's right-click "Command Palette" opens oculus's command mode (Z744), so no route opens Monaco's palette once F1 is taken from it.
