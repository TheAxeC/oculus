# Brief: P3, boards parity

Read `../spec.md` first; it governs this package unchanged. Then `../../parity.md`, its "Projects, Archive, Coauthor" section. The three boards landed in O10 as the shared board with cards, list, facets and search; the cockpit's Projects tab carries a stats strip, quick filters, type toggles, bulk controls, and per card a pin, a subtasks block and a file finder that the boards do not. This package makes the boards carry what the tab carries, on oculus's design: `state/board.ts` for the counting, the primitives, P1's write path (`state/writes.svelte.ts`: `writeManifest`, `writeSubtask`, `addSubtask`, `newIdea`; read that file whole).
