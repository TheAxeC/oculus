## What to build

1. **Files, the explorer.** One tree per served root under a collapsible root header (the root's name in small capitals, its actions shown on the header's hover: add a root, the workspace choice, refresh, collapse all). Rows of one fixed height with an indent guide per level, an expand arrow on folders (rotating when open), the file-type icon the tree already draws, the name, and the row's actions (bookmark, open in a new tab, and for a folder new note where the view has it today) shown on hover or on the focused row only. Hover and selection draw a row highlight in theme tokens; the selected row is kept in the instance state. The keyboard moves along the rows (Up, Down, Home, End), Right opens a folder or moves into it, Left closes it or moves to its parent, Enter opens the selected file as today. A filter field above the tree narrows the rows to names containing the text, their parent folders kept open. A breadcrumb above the tree names the selected row's path by its segments, each segment selecting that folder. Bookmarks, Notes and Workspaces become collapsible sections under the tree in the same row style. Every action the view offers today stays reachable.
2. **Repositories, Source Control.** One repository at a time: a repository picker at the top (the roots the channel carries, the one shown kept in the instance state). Under it the collapsible sections Changes (with the staged, changed and untracked groups as today), Commits, Branches and Worktrees, each header with its count; rows in the explorer's row style, each row's actions (the presses the view offers today, the diff opening included) shown on hover or on the focused row only. The confirm dialog and the write answers stay as they are.
3. **Look.** Both views use theme tokens only; the row height, indent and hover colours are tokens or catalog-free CSS in the view; icons from `config/glyphs.yml`, where you may add the names you need (an expand chevron, a collapse-all) with their Lucide icons in `config/icons.yml` and ASCII stand-ins.
