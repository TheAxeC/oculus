## What to build

1. **The 13 slides, by the named script (Z234).** From the repository root of the worktree, run this and nothing else to write the 13 lines; it replaces each `  equation: eq_<id>.png` line with the entry's LaTeX as a single-quoted YAML scalar (Z224) and refuses unless exactly one line changes in each of the 13 files:

   ```sh
   python3 - <<'EOF'
   import re, pathlib
   eqs = dict(re.findall(r'^ "(eq_[a-z]+)": r"(.*)",\s*$', pathlib.Path('tools/present/make_equations.py').read_text(), re.M))
   files = sorted(p for p in pathlib.Path('projects').rglob('PRESENT.md') if '  equation: eq_' in p.read_text())
   assert len(files) == 13, len(files)
   for p in files:
       text = p.read_text()
       new, n = re.subn(r"^  equation: (eq_[a-z]+)\.png$", lambda m: "  equation: '" + eqs[m.group(1)].replace("'", "''") + "'", text, flags=re.M)
       assert n == 1, (p, n)
       p.write_text(new)
       print(p)
   EOF
   ```
