## What to build

The status bar as VS Code draws it, every row of the inventory in `agents/reviews/vscode-parity.md` "Status bar" except "Debug colour while debugging", which D11 owns:

| VS Code | built here as |
|---|---|
| A 22 px bar, 12 px text | a 22 px bar (`--status-height`), every item at 12 px (`--status-text`), both fixed at every text scale; the items flush, 0 8 px padding, a hover fill |
| Left group and right group | left: host, branch, sync, findings, HPC, usage, server; right: the source tab's items, live sessions, unsaved tabs, the bell last |
| Remote or host indicator | the machine oculus runs on, by name, first on the left; tooltip the server's address; a click opens the Status view |
| Git branch, switch on click | the branch of the repository holding the active tab's file, or the hub's own repository when the tab holds no file, with the branch icon; a click opens a picker of that repository's branches through the existing menu primitive, and a choice switches through the existing `switchBranch`; a detached head shows the short commit |
| Sync status, sync on click | ahead and behind as up and down arrows with counts, beside the branch, once the branch has an upstream; a click pushes through the existing `push` when ahead and not behind, and opens the Repositories view otherwise |
| Problems count, opens Problems | the count of the Findings view's list (the snapshot's findings and the config channel's) with its icon, opening the Findings view |
| Notifications bell, the notification centre | a bell at the far right with the count of unread notifications; a click opens the centre above the bar's right end: the list, newest first, each with its words, its time and its actions, Clear per entry, Clear all, and Do Not Disturb, which stops the toasts and keeps the list; a new notification shows as a toast above the bar's right end for 8 s or until closed |
| Line and column, go to line on click | "Ln 12, Col 4" for the active source tab, "(3 selected)" appended for a selection; a click opens the palette on `:`, and `:` followed by a number moves the tab's caret to that line and scrolls it into view |
| Indentation, change on click | "Spaces: 4" or "Tab Size: 4", read from the file's own lines; a click opens a menu of Indent Using Spaces and Indent Using Tabs, each with 2, 4 and 8, and Convert Indentation to Spaces or to Tabs, which rewrites the tab's text as unsaved; Tab in the editor then inserts that indentation |
| Encoding | "UTF-8", its tooltip saying oculus reads and writes UTF-8 |
| Line endings, change on click | "LF" or "CRLF" from the file's text; a click offers the other, which rewrites the tab's line endings as unsaved |
| Language mode, change on click | the highlighter's language for the tab, by name; a click opens a searchable list of every language `state/words/languages` knows plus Plain Text; a choice recolours the tab and is kept in its instance state |
| Right-click to hide items | a right-click on an item or on the bar opens a menu of every item with a check; unchecking hides it; the hidden set is kept in the UI store with the appearance |
| Items an extension adds | the server, usage, HPC, live sessions and unsaved items stay, each an icon, short words and a tooltip with the long words |

Every item is a button with a tooltip, reached by Tab, acting on Enter. Every icon comes from `config/catalogs/glyphs.yml` and `icons.yml` (added where missing); every word from `config/text/`.

Notifications are posted for five events, each once per event and never again for the same state on a later push, each through one call to the notification store:
1. a rail write the server refuses (`railRefusal`), which replaces the fixed refusal line;
2. a session whose count moves it into waiting for input, with Open, which shows that session;
3. an update task whose last run moved (a feed's `lastRun` or `lastPost`, or the triage's `notesRun`), with Open, which shows that feed's view;
4. a Live HPC job that newly appears in `recent`, finished or failed by its `state` and `exit`, with Open, which shows the Live HPC view;
5. a write the server refuses or fails (`refused` non-empty or `error` set on a `WriteAnswer`), beside the line the view already draws.

The source view publishes its caret, selection, indentation, line ending and language to a state module the shell may read, keyed by instance; the bar reads the active instance's. The machine's name is added to the `config` channel's payload and handed to the page in `StatusWords`.
