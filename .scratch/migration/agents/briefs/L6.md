## Decisions taken in this brief (each reversible, none silent)

1. The bar height and text size are fixed tokens, as the rail's are, so a larger text scale leaves the bar's height alone.
2. The branch shown is the active tab's repository, as VS Code shows the active editor's; the hub's own repository when the tab holds no file.
3. Sync pushes only when ahead and not behind; behind opens the Repositories view until X3 adds pull.
4. Go to line is the palette's `:<number>`, since the palette is oculus's quick input and its commands are words.
5. The hidden items are kept per browser in the UI store, as the appearance is.
6. Encoding shows UTF-8 and offers no change: oculus reads and writes UTF-8 only.
