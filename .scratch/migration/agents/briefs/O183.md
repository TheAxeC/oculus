## What to build

The plan's ruling "Open item 750": (a), the prompt box goes from the Live view, whose terminal then takes the whole height, and stays under the Transcript view.

1. `TerminalGrid.svelte` draws no `SteerBox`: the block at `:478-480`, the `agent` derived at `:199-200` and the import at `:52` go, so the grid of every terminal, an agent's or a shell's, takes the whole height of its box.

3. The Transcript view keeps its box unchanged.

## Cases

- A Live terminal running Claude: the grid reaches the bottom of `.terminal`'s inset, as a shell grid does; no text box, Send or Stop under it; the agent's own input line sits on the grid's last rows, with no empty band under it, since the resize sends the full height.
- A Live terminal running Codex: the same.
- A Live shell terminal: the grid fills the body, as today.
- A split tab with an agent and a shell side by side: both grids reach the bottom of the inset.
- A by-hand pane running an agent: it keeps its own size, scrolls inside the taller grid, sends no resize, and draws no box.
- A foreign terminal on Live: no line saying it cannot be typed into from here; the Transcript view's box still says it.
- An agent started in a shell terminal, or an agent that exits: the grid's height does not change, and no resize follows from the change of kind.
- A running agent whose session the page cannot link yet (no Transcript switch): no box anywhere in the tab; typing goes into the grid.
- The Transcript view of a live session: the box with Send and Stop under the turns, as today.
- The Transcript view of an ended session: the box's line saying the session ended, as today.
- A locked tab on Live: the grid takes no typing, paste or drop, as today, and the box's locked line is no longer drawn there.
