## What to build

1. **Repository or not, told apart.** The reader decides whether a root is a repository with `git rev-parse --git-dir` (list arguments through the existing `run`, the same timeout). `GitState` gains `repository: boolean`: true for a repository whatever else failed, false for a folder that is none and for a directory that does not exist.
2. **An unborn branch reads.** A repository with no commit yet reads its branch with `git symbolic-ref --short HEAD`, has no error, an empty log, no ahead or behind, and its untracked and staged files as `git status` gives them.
3. **The picker.** It lists every root whose state says `repository: true`, labelled as today; a repository whose read failed (its `error` set) stays in the picker and the view draws its error as one muted error row in the explorer's row style (a catalog key under `repositories.*`), in place of the sections. The shown repository is kept while it is a repository, so a read that fails once no longer swaps the view to another repository.
4. **The `upstream` comment** in `model-sessions.ts` and any sentence that says an error means "not a repository" follow the new field.
