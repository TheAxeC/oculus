## What to build

1. **The row on every card.** `ProjectCard.svelte` draws the Deposit row in its menu for every project, on every page that draws the card: the Projects boards, the Person view, a Listing and the project page. The prop `deposit` is removed with its doc comment and its default; the row is part of the card's actions with no condition, and it still opens the deposit view beside the card through `openBeside('deposit', recordField(item.id))`. Its place in the menu stays the one `record-menu.ts` gives it.
2. **The project page.** `Project.svelte` stops passing `deposit`. Its head comment says the card is drawn with `page` on, and that the card carries the deposit control on every page, so the sentence about the deposit control no longer reads as this tab's alone; the words about the deposit mirroring `code/` stay.
3. **The comments and the help.** The head comment of `ProjectCard.svelte` says every card carries the Deposit row, in place of the sentence about the project view passing `deposit`. `docs/HELP.md:299` drops "(on the project page)", so the run reads "... Copy Context, Deposit and Clone, ...". Every other sentence in `src`, `docs`, `README.md` and `config` that says the deposit is on the project page alone is rewritten (grep `deposit` and `Deposit` over them; each hit is read).
