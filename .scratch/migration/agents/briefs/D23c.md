## What to build

### Part 1, a library file (Z669 (a))

What must hold when the part is done:

1. A location a language server names in an answer to a page request, whose file lies outside every served root, reaches the page as a library address instead of being dropped. A library address names no path of the machine: it is `oculus-lib:///<token>/<file name>`, the token minted by the relay for that page and that real path, the file name percent-encoded. The same real path named again to the same page gets the same token.
2. The relay keeps, per page, the tokens it minted for that page, each with the real path, the root and the language of the server whose answer named it. A token lives as long as the page's connection; another page holds none of them.
3. Only answers mint a token. A notification (`textDocument/publishDiagnostics` and the rest at `relay.ts:805`) or a server's request (`workspace/applyEdit`) that names a file outside every root passes that location to the page only when the page already holds a token for it, and drops it otherwise. Every field follows this rule, a command's `arguments` and a workspace edit's `changes` keys included, so no `file://` path of the machine reaches the page in any field (`uris.ts:277` and `:283` today pass it raw).
3a. A token is keyed by the real path, the root and the language of the server that named it, so a file two servers named to one page is two tokens, each tab served by the server that named it. A file whose name holds `%` is encoded as the root key is (`kit/lsp/uris.ts:5-7`), so Monaco's one decode gives back the encoded name.
3b. No token is minted, and the location is dropped, for a path the file routes would never serve whatever the roots: a path with a segment that starts with a dot, a path under a folder `closed_paths` names (`closedPaths`), the engine's `config/` folder (its `local.yml` above all), `~/.oculus`, and the hub's `secrets` folder.
4. The page reads a library file through the `lsp` channel: a page message `{ oculus: 'read', root, uri }` answered by `{ oculus: 'file', root, uri, text }` or `{ oculus: 'file', root, uri, code }` with a refusal code. Both are added to `LspToServer` and `LspToPage` in `data/model/model-processes.ts` with doc comments, and the relay answers the read only for a token of that page. It refuses, with a code and without reading anything: a token the page was not given (a forged one, another page's), a read whose `root` or channel language is not the token's, a token whose root is no longer served (answered with a code, since `#oculus` answers nothing for an unserved root today), a path that is no longer a regular file, a path whose real path resolved again differs from the one stored with the token (a symlink retargeted), a file that is not text (`isBinaryFile`), and a file over `TEXT_LIMIT`. The read reads the stored real path alone.
5. A library address in a message from the page to a server is turned back into the `file://` URI of its real path, so the server can be asked about the file (hover, go to definition, document symbols inside the library tab); a library address the page was not given refuses that message whole, as an unresolved page address is refused now. A library tab's `didOpen` opens the document on the naming server under that `file://` URI (`#didOpen` today takes only addresses under a served root), so hover, definitions and diagnostics answer inside the tab; after a server restart the document is opened again on the new server as every other open document is.
6. Go to definition (F12, Ctrl or Cmd click), go to declaration, go to type definition and go to implementations that land in a library file open a read-only source tab of it at the definition, with the symbol selected (Part 2). Peek (Alt+F12) shows the library text read through the channel. Inside the library tab, hover and go to definition answer from the server that named the file, and a definition in another library file opens another library tab. The tab's language is the naming server's language stored with the token, so an extensionless header (`string`, `vector`) is C++ with its highlighting and hover. A library file no server's language covers opens read-only as plain text.
7. A library tab is read-only: the editor's `readOnly` is set, as for a file locked by its mode (`DESIGN.md:510`), nothing offers Save, rename and code actions offer no edit, and no write route is reachable from it. Its title is the file name, and its note says, from the catalog, that it is a library file a language server named, shown read-only. A library tab whose token the page connection does not know, after a reload or after the socket reconnects without a reload, reads nothing and shows a sentence that the library file is no longer open and that go to definition opens it again. A References result saved with the layout whose row names a library address shows that sentence on a press.
8. DESIGN.md states the rule: "Language server channels" (`:123`) gains `read` and `file` among the relay's own messages; the bullet on a file locked by its mode (`:510`) names the library tab as the other read-only source tab; "The language servers" (`:571`) states the library address, what mints a token, the paths that mint none, and that a page reads only a file a server named to it; the References bullet (`:522`) says a saved library row opens nothing after a reload. `uris.ts`'s head comment states the same in place of the drop sentence. `docs/files-and-search.md` "Language servers" tells the reader that a definition in a library opens read-only, and `docs/views.md` "References" (`:69`) says a press opens the location with its word selected.
9. The relay's read is a unit under G2 with one test written as a table, one row per outcome of item 4, item 3b and item 5's refusal. The builder never edits `agents/guarded.md` (the rules file bans every edit under `tools/oculus/.scratch/`): the report gives the G2 sentence of Decision 5, its Code line and its Test line, and the G3 Code line for the new module that refuses `config/local.yml`, and the orchestrator writes them into `guarded.md` at landing.

### Part 2, the symbol selected on open (Z670 (a))

What must hold when the part is done:

1. `SourceTabState` takes `column?: number` beside `line`, read through a shape that takes anything but a positive finite number as no column, so a saved layout without it reads as before (G29).
2. `sourceTabState(root, path, line, column)` and `openSourceFile(client, { root, path, line, column })` carry it; `LspServices.open` passes the column the opener has (`hosts.ts:119-124`, the start of the location's range, or of `targetSelectionRange` for a LocationLink) through `language/lsp.ts:153` instead of dropping it. `LspServices.open` and `readFile` take a library address for a library file, since a library tab has no root and path of a served root; the saved shape of a library tab is `SourceTabState` with its library address in place of `root` and `path` (Decision 7).
3. A source tab opened at a line and a column selects the word at that position once the text is in (the identifier under it, from Monaco's model), and places the caret there with nothing selected when no word is there. The opened-at effect of `Editor.svelte` acts once per line and column the tab is pointed at, so pointing an open tab at another symbol of its file selects that one.
4. No new option is added to `goto`: the selection uses the existing `select` request (`editor-status.svelte.ts:70`). The status bar's Go to Line/Column and the palette's go to line keep `goto` as now and select nothing.
5. An Outline press on a language-server symbol of the open tab selects the symbol's `selectionRange` through the existing `select` request: the row carries the range's end beside its start (`symbols.ts:104-105`); a heading row (Markdown, LaTeX) goes to its line as now.
6. A press on a location in the References view opens it with its column and selects it the same way (Decision 3).
7. A tab whose `column` is past the line's end is clamped as `goto` clamps it now.

## Decisions taken in this brief (each reversible, none silent)

1. The library address is an opaque token with the file name, `oculus-lib:///<token>/<file name>`, so the page never holds a path of the machine for a document (DESIGN.md "The language servers"), and the tab can still be titled by the file name. The other way, the real path in the address, was not taken because the page would then hold machine paths for documents and a forged path would have to be checked against the same token map anyway.
2. A token lives as long as the page's connection, so a library tab restored after a reload shows a sentence instead of reading the file; the read stays limited to what a server named to the page now.
3. The References view passes its column too: it opens a location through the same `openSourceFile`, and leaving it at column 1 would keep the defect Z670 ends for that opener.
4. A library file over `TEXT_LIMIT` is refused rather than shown cut, since a language server answering over a cut text would point at wrong places.
5. G2's sentence, written by the orchestrator at landing from the report, becomes "A path outside the configured roots is refused, except a file a language server named in an answer to the page, which that page alone reads, through the `lsp` channel.", with a Code line for the relay's read and a Test line naming the new table test. This states the exception Z669 (a) rules, so G2 is not false after the step.
6. On open, "the symbol's range" is the word under the column from Monaco's model (`getWordAtPosition`), selected through the existing `select` request, since the tab's state takes a column alone (Z670 (a)) and a definition's start column is the start of its name. The Outline, which has the symbol's `selectionRange` at hand, selects that range exactly.
7. A library tab's saved state holds its library address in place of `root` and `path`, so a restored tab knows it is a library tab and shows the sentence of Part 1, item 7.
8. A token dies with the page connection, a socket reconnect included, since a relay cannot tell a reconnected page from a forged one without a new page identity on the wire.
9. The read's messages are `{ oculus: 'read', root, uri }` and `{ oculus: 'file', root, uri, text | code }`, `root` being the naming server's root as on every other relay message of a channel; the refusal codes are `unknown`, `not_served`, `not_file`, `moved`, `binary` and `too_large`.
