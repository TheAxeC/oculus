## What to build

1. **The rule is Q85a1's, as Q85a2 applies it.** A schema goes where a map or a list that came from outside the process is read for its named fields or its items. The schema is a `const` beside the function that reads, in that function's file, named in lower camel case ending in `Shape`; a schema whose answer has a declared type is held to it with `satisfies z.ZodType<...>`. The function answers, for every input, exactly what it answers on main: the same value, the same null, the same thrown or answered sentence, the same keys, absent keys absent. zod's own error text is never shown or logged. A reader that builds its answer from named fields reads them from `safeParse(...).data`; a reader that hands on an object or an array it was given answers the input value itself, so its identity, the order of its keys, an own `__proto__` key and keys the schema does not name all stay. Five rules keep the answers the same, each found by a probe of zod 4.6.5 (Q85a2's brief check): a whole number is tested as the hand code tests it, `z.number().refine(Number.isInteger)`, never `z.int()`, which refuses `2 ** 60`; a number the hand code accepts with `typeof === 'number'` stays accepted when it is `NaN` or infinite; an optional field is `.optional()`, never `.nullish()` or `.catch`, where the hand code refuses `null`, and a field the hand code reads with a fallback for any other value (`text(x)`, `typeof x === 'string' ? x : ''`) is `.catch(<fallback>)`; a field read as a raw `first ?? second` reads the second only when the first is `null` or absent, whatever type the first has, while a read through a helper (`str(a) ?? str(b)`, `text`) falls back whenever the first is not a string, and each keeps its form's answer; keys read from a map are read from the input's own keys in their order, never from `z.record`'s `data`, which drops an own `__proto__` key. The body readers are held to the same answer for every JSON value, since each route hands them `JSON.parse`'s result; the file and answer readers keep their answers for every value.
