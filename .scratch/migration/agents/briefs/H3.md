## Conventions

On top of `agents/spec.md`, the hub's rules for every document (the "Writing docs" rules of the hub's instruction file, restated here because `spec.md` keeps builders from reading that file):

- One line per paragraph and per list item; hard line breaks only between paragraphs and list items, at headings, in tables and in code blocks.
- ASCII only: `...` for an ellipsis; no em dash or en dash in prose, reworded with a comma, a colon, a semicolon, parentheses or a new sentence; a spaced hyphen ` - `, `--` or `---` standing for a dash is the same fault; `-` only inside a compound word, a number range or a quoted title; arrows as a word or `->`; straight quotes; ` | ` for a separator, ` / ` inside a Markdown table.
- No history: no dates, no "was", "used to", "no longer", "replaced", "retired", no step ids or ruling numbers; the map states what is.
- No chatbot framing, no filler words (leverage, comprehensive, crucial, showcase, moreover), no forced groups of three, no synonym cycling: once a thing has a name (entry, field, key, link, view), that name every time. A "Shown in" cell names views and nothing else.
- Every path the map names is written from the hub root (`tools/oculus/config/catalogs/manifest-schema.yml`, `projects/archive/`), so a reader at the hub root finds it; a path inside a folder that varies is written with a placeholder (`projects/<tier>/<id>/code/README.md`, `network/<event>/`). A bare file name (`project.yml`, `README.md`) names a kind of file, never a path.
- Real Markdown tables with short cells, so the grid renders; a cell that needs a sentence is split into a table row and a note below the table.
- Lead with the answer; short plain sentences; bold only for real labels.
- In `tools/oculus/` files, the rules of `spec.md`: in YAML (`sources.yml`, `layout.yml`, `config/text/app.yml`), one line per entry and one line per comment paragraph ("What every package obeys": one line per paragraph in any YAML you edit); in `docs.ts`, the head comment paragraph rewrapped at 100 columns as a whole, and four-space indentation.
