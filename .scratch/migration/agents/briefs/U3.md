## Cases

Proven by a test (a string render with `svelte/server` in the `unit` project, or a pure function):

1. `fit([20, 20, 20], 100, 20, 4)`: 3, no opener. `fit([20, 20, 20, 20, 20, 20], 100, 20, 4)`: 3 (3 x 20 + 3 x 4 + 20 = 92 fits, a fourth does not). `fit([20, 20, 20, 20, 20], 116, 20, 4)`: 5, no opener (all fit). `fit([200], 100, 20, 4)`: 0. `fit([], 100, 20, 4)`: 0, no opener. Room 0: 0. A width that is not a finite number counts as 0.
2. A Pane with no toolbar and no bar renders no bar strip; with a bar and no toolbar it renders the strip; a header Toolbar with `overflow` renders the `more` button markup only when told some control is clipped.
3. The Projects view renders its Search, filter Menu, type and quick toggles and both Segments inside the bar, and only bare icon actions inside the header.
4. The Collection view renders `collection.add` as a bare icon on the `add` glyph with its words as `aria-label`; `glyphs.yml` and `icons.yml` hold `add`, and the config checks pass.
