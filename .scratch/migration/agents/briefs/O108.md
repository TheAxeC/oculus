## What to build

`npm run app:package` and `src/desktop/package.ts` are gone, and nothing in the repository makes an app that runs the checkout. `npm run app:release` makes the app, its output byte for byte in the same places, and `npm run app` is unchanged.

- `package.json`: the `app:package` script line is removed.
- `src/desktop/release-steps.ts` (new): the helpers `release.ts` imports, and only those, with `NAME` as the helpers need it, moved unchanged in behaviour, with a head comment in the repository's form saying what the file is. No launcher code moves: `defaultOut`, `writeStub`, `finishSteps`, `main` and `startedAsProgram` are deleted, and an import or constant only they used goes with them.
- `src/desktop/release.ts`: imports from `./release-steps.ts`; its head comment no longer names `app:package` or a stub and says what the app is.
- `tests/server/desktop/platform-steps.test.ts`: imports from the new file; the `finishSteps` rows go, its head comment names the new file; the release's programs stay checked through `iconSteps`, `archiveStep` and `signSteps`.
- `tests/server/desktop/script-args.test.ts`: imports from the new file; its head comment names `npm run app:release` and the new file alone.
- `src/desktop/package.ts`: deleted.
- Generated diagrams are left to the landing.

Installing the app is no part of the builder's work: the orchestrator has replaced `~/Applications/oculus.app`, and the builder touches nothing outside its worktree.
