## What to build

1. **The in-memory path for unit directives.** `bin/revert-check.mjs` starts one Vitest instance for the run (the mechanism of premise 3, with `root` the tree the check reads), when at least one directive names a unit case, and closes it at the end of the run, on every exit path. For each directive that today reaches `runCase()` for a unit case, in the order `main()` runs them:
   - a **baseline**: the case is run once in memory with no revert, once per case name per file (kept for the run); a case that does not pass there takes the copy path for its directives, so a red in memory is only ever a case that passed without its revert;
   - the **revert in memory**: the reverted text served through the plugin's `load` for the target's absolute path, the target invalidated before and after, the name pattern anchored to the whole case name, and the case's result read by its exact name. Exactly one result with state `failed` is `red`, printed as today.
   - **the fallback**: a result `passed`, no result, more than one result, or a run that throws, sends the directive to today's copy path unchanged, whose verdict is printed.
   Every check `checkOne()` makes before its copy (the problem, no case, outside the tree, no file, a folder the copy leaves behind, the edit changing nothing, no line, the `node --check` of a reverted `.mjs`/`.cjs`/`.js`) still runs first and still answers first, so a directive the copy path would refuse is refused with the same line.
2. **Browser directives unchanged.** A directive whose file `isBrowserCase()` names goes straight to today's copy, build and Playwright run.
3. **The output unchanged.** The lines and the summary line are word for word today's; nothing says which path proved a line.
4. **The run's temporary directory.** The in-memory run sets `process.env.TMPDIR` for its own duration to one folder made for the run under the system temporary directory, and removes it at the end and on a signal (the handlers of `SIGNALS`), so an in-memory run leaves nothing in the system temporary directory, as the copy path already does.
