## Decisions taken in this brief (each reversible, none silent)

1. The sum is made on the page from the rows the server already sends, not on the server: every counted file under `src/` is in exactly one row under `src` (the premise above), so the sum is exact, and the answer's shape (`LineCount`, read by `readCount`) stays as it is. 2. The row is labelled `src/`, the step line's own name, with the trailing slash that tells it from the existing `src` row of the six files directly in `src/`. The label is the path built from item 1's constant (the constant followed by `/`), as every folder row shows its path from data; a path is not a catalog sentence, so no catalog key is added. The `src` row keeps its name.
3. The row sits directly before the first row under `src`, heading the rows it sums, and carries no languages, since the step asks for one row. A folder such as `src-old` that sorts among the `src` rows is not moved: the rows keep the server's path order.
4. The row is drawn as a folder row, not bold; bold stays the total's alone.
5. The key is `sum:src/`.
