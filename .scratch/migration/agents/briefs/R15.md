Read `../spec.md` first, its section "The principles every package is judged on" above all. Axel ruled on 2026-09-14 at 08:30 (ruling (b) of the sharp-edge audit): the Claude Code hooks that post to oculus fire only for sessions started in the hub, because the block lives in the hub's `.claude/settings.local.json`; the block moves to `~/.claude/settings.json`, which every session reads, and oculus prints it as a snippet he installs, with the hook commands carrying a one-second timeout so a stopped oculus costs a session nothing.
