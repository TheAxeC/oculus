## What to build

1. **The Awaiting box's names are buttons.** Each name of the box is drawn as a plain button (`ToolButton plain`, as the band's card titles are), the separators between names kept as now, and the count stays in the name ("BSPC (2)"). The box's look is otherwise unchanged.
   - An Applications name opens that entry's page, and a Grants name the funding scheme's page, each through `pageView` with the collection and registry of the entry's own hub, the page a card title of that entry opens. Two entries with one title are two names, each opening its own page; while the workspace has more than one hub, a name of a hub other than the primary carries its hub's name after it, so two such names never read the same. An entry with an empty title is named by its id, as `openPage` does (`Collection.svelte:205`). A grant whose hub names no funding collection (`fundingKey` undefined) is drawn as plain text, never a button to an empty page.
   - An Under review name, a Waiting on name and the Blocked count each open a transient board (item 2) of the projects that name counts in the box.
2. **The Awaiting box's transient board.** One view of the project board component, id `awaiting_board`, its words `views.awaiting_board` ("Awaiting") and `views.awaiting_board_glyph` in `config/text/views/boards/projects.yml` beside `track_record`, registered beside the track record's as the module's own view (not listed in the view catalogue, no count on its tab or the rail, kept through every push of `boards:`), drawing as board cards exactly the projects the pressed name counts, in sections by `categories:` as a board of `boards:` draws them.
   - Its tab state is `{ id, row, name, title, filter }`: `row` the box's row (`review`, `people` or `blocked`); `name` the tally's label as `waiting()` keys it, without its count (`''` for Blocked and for a project with no venue, so the venue-unset words appear only in the title and a venue literally named "(venue unset)" is a different name); `title` the tab's title; `filter` the Focus filter in force at the press; and `id`, the tab's identity, `<row>:<name>`. Its title is the row's label and the name, `'{0}: {1}'` (a new word of the text catalog beside `board.record_title`), as in "Under review: BSPC" and "Waiting on: Maryam", and "Blocked" alone for Blocked. A second press on the same name brings that tab forward with its `filter` set to the Focus filter in force at that press. The board's Mine only starts in the state of the carried filter's `mine`, so a Focus filter with Mine only off opens a board with Mine only off. A tab opened with no state or a state that does not parse (from the palette, or a saved layout) draws a message in the shape of `board.record_no_role` (a new word `board.awaiting_none`: "This tab was opened for no name of the Awaiting box. Press a name of Focus's Awaiting box to open its projects."), never a board of every project.
   - Its take is computed from the live portfolio each time it is drawn, by the one rule the box counts with: `waiting()` keeps, for each tally, the ids of the projects it counts, each project once, and the board takes the ids of the tally of its row whose label is its name, over the portfolio the Focus filter it carries keeps (the Focus page's own filtering, `focusPage`), so the board holds what the name counted at the press and follows the portfolio afterwards: a project that stops waiting leaves the board, and a board left with none draws the empty board's message.
   - The take is a key of `BoardRule` that no row of `boards:` names, as `record` is (null on every board read from a row and on the record's board), so `boardTakes`, the audit and New project read it through the one rule: the board offers no New project.
   - The board's own bar works as on every board (search, quick toggles, groups, Mine only), narrowing what it holds.

A row naming a project opens the project's tab as now; a lead line reveals the lead in the Leads view as now; an inbox, LinkedIn or refresh line opens what it opens now; a row naming no entry opens its collection's view as now.

## Decisions taken in this brief (each reversible, none silent)

1. The transient board holds the projects the name counted under the Focus filter in force at the press, carried in the tab's state, so the board's count equals the name's count (case 7). 5. An Applications or Grants title held by two entries is drawn as two names, each a button to its own page, in place of one name counted "(2)": one button can open one page. The counted form stays for Under review and Waiting on, whose names open one board.
6. 7. The board's Mine only starts at the carried Focus filter's `mine`, and a second press refreshes the carried filter, so the board holds what the name counts (cases 9 and 10).
