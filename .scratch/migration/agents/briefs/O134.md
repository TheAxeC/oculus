## What to build

1. A section `## notes/<name>.md` between the end of the update tasks section and `## project.yml`: one sentence saying what a note is and where it lives (a Markdown file in `<hub>/.oculus/notes/`, its name its title), then a copyable head fenced as `markdown`: a `---` line, `tags: []` with a comment on what the list takes, a `---` line. Then the rule it follows, in short sentences: `tags:` is the one key oculus reads, as a list or one text of words split on spaces and commas; a `#word` in the text is a tag too; any other key is kept in the file and not read; the head is hidden in the preview and the editor.
2. A row in the table of "Where each file goes", after the row of `tasks/<task>.md`: File `notes/<name>.md`, Place `<hub>/.oculus/notes/`, Who writes it "New Note, or you" (New Note writes the empty file; the head is the user's).
3. The bullet of line 34 keeps `order.json` alone: "`<hub>/.oculus/notes/order.json`: the order the Notes list shows the notes in." in the builder's words, so the sentence over the bullets ("Oculus writes these itself, so they have no template") stays true.
