## What to build

1. **Hidden and ignored files.** Two toggles in the Files view's header, beside the add-root control, worded `hidden files` and `ignored files` from a catalog key each. Both off by default and kept per tab in `FilesView` (`hidden: boolean`, `ignored: boolean`). A listing request carries them as `hidden=1` and `ignored=1`, the shape Axel ruled on 2026-09-23. Without `hidden=1` the server leaves out what it leaves out today; with it, it sends dotfiles and the three build folders too. Without `ignored=1`, the server leaves out every entry git ignores, read with `git check-ignore --stdin` (one run per listed folder) in a root that is a git repository; a root that is not a repository leaves out nothing for that reason. Flipping a toggle reads every expanded folder of that tab again. The filter and the reveal keep working over what is drawn.
2. **One bar in a source tab.** Save, Revert, Preview and Bookmark this file sit in the pane's toolbar on one row, in that order, with the program button after them when the file has one; the body no longer draws its own control row.

6. **The refresher's words.** A healthy refresher reads `ok, last HH:MM, next HH:MM`, the next time being `lastRefresh` plus `usage_refresh_min`; `refreshing` shows only while a refresh runs; the stale and down lines keep their meaning. Every word from `config/text/views/system/usage.yml`.
