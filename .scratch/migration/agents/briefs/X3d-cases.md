# X3d, the ruling on the cases (round 0)

The first run handed back case 31 and four places where item 17 does not match `seti-ui`'s files. Each is ruled here inside the step, under Axel's ruling of 2026-09-25 ("the Seti set (`seti-ui`) with its own table and colours"). The brief `agents/briefs/X3d.md` and `agents/spec.md` still govern; everything else stands as the brief says.

1. **Case 31.** `package.json` takes `.json`'s entry (glyph `json`, yellow), since `mapping.less` has no `package.json` entry and VS Code's `vs-seti-icon-theme.json` has none either. The witness that a name's entry wins over its extension is `tsconfig.json`; the witness that the longer ending wins is `a.test.ts`. The other seven names stand as the builder's first run resolved them.
2. **Where item 17 reads from.** `file-icons.ts` reads the three files of `seti-ui` that hold the table: `styles/components/icons/mapping.less` (name or ending to glyph name and colour name), `styles/_fonts/seti.less` (glyph name to character) and `styles/ui-variables.less` (colour name to value). The font drawn is `seti-ui`'s own `styles/_fonts/seti/seti.woff`, since its characters are the ones `seti.less` names.
3. **The glyph's size.** VS Code's theme gives no size per entry; its one font record says `size: "150%"`. The glyph is drawn at 150% of the row's font size, in a 16 px wide box, as VS Code draws it.
4. **The colours.** They are Seti's own, as the ruling says, and are drawn through tokens as every colour is: `themes/tokens.css` gains one token per Seti colour name the table uses (`--seti-blue`, `--seti-yellow`, `--seti-grey-light`, `--seti-ignore`, `--seti-white`, `--seti-primary` and the rest), each set to the value `ui-variables.less` gives, and `FileIcon.svelte` draws `var(--seti-<name>)`. They are the same in every theme, as VS Code's Seti colours are.
5. **The matching order.** The brief's order stands: the file's name first, then the longest ending, then the table's default, which is how VS Code reads its Seti theme and how the brief's "as VS Code draws them" is met. Where the stylesheet's own last-match order differs (the builder found six, `pom.xml` and `README.txt` among them), VS Code's reading wins; a case covers `pom.xml`.
6. **The test attributes.** `data-file-icon` and `data-colour` on the drawn icon stand as the builder chose them.
