## What to build

1. **`config/appearance.yml`**: a section after `crt:` with a comment in the file's shape and `code_theme: tokens`. The comment says: `tokens` colours code from the UI theme's own code tokens; any id of Shiki's bundled themes (such as `dark-plus`, `github-light`, `nord`) takes that theme's syntax colours, while the editor's background and chrome stay on the UI theme; the Settings view's Code theme menu writes the viewer's own choice into the appearance store, as the CRT toggle does. The head comment (3-4) names the code theme among what the file holds.
2. **`src/lib/data/sources/config/catalogs.ts`**: `code_theme` joins `VOCAB_KEYS`, so the first frame carries it.
3. **The list of code themes**: `src/lib/data/helpers/code-themes.ts` (the folder's tenth item), exporting `CODE_TOKENS = 'tokens'`, `codeThemeIds(): string[]` (from `shiki/themes`'s `bundledThemesInfo`, in its order) and `codeThemeInfo()` answering `{ id, label, dark }[]` (label the entry's `displayName`).
