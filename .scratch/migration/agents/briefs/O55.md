### 3. Boards: keys, the six boards, a project on every board it meets

A project is on a board when it meets every key the board names; every list named must hold. A word, flag or role key its vocabulary does not hold is a finding of the config check (`boardsFindings`, G116); the options catalog takes the role keys from a new source `roles` and the stage flags from the flags the rows of `stages:` carry.
- The six shipped boards, in this order in `boards:`, the view registrations and the Projects page's default pane: `projects` (`tier: research, role: lead, stages: { not_flags: [terminal] }`), `supervision` (`tier: research, role: supervisor`), `coauthor` (`tier: research, role: [collaborator, other]`), `archive` (`tier: research, role: lead, stages: { flags: [terminal] }`), `personal` (`tier: personal`), `software` (`tier: software`).
