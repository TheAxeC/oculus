## Decisions taken in this brief (each reversible, none silent)

1. **The recovery is a terminal action.** `server/pty/routes.ts` gains `action: 'recover'` with `{ key, cols, rows }`: the key must be a dataset key of the snapshot the server holds (`portfolio`'s `entities.datasets`), else 400; the terminal is started as kind `shell` in the hub root with `command` (`server/pty/sessions.ts` line 96, server-side only today) set to `python3 tools/data/redownload.py <key>` with the key shell-quoted, and named `recover <key>`; the answer is the same `{ ok, terminal }` as start. `state/terminals.svelte.ts` gains `recoverDataset(key, cols, rows)`. `tests/routes/terminal.test.ts` covers a good key, an unknown key and a key with a shell character (refused by the dataset-key check, since no dataset key holds one; the check is against the snapshot, not a regex).
2. **The registry is a collection too.** `config/sources.yml`'s `collections:` gains `{ key: data, title: "Data", file: registries/data.yml }`; `REGISTRY_KEYS` (`normalise.ts` line 52) holds `datasets`, so the key `data` is not filtered by it: it is added there so `registerCollections` does not register a generic view for it, and this package registers `data` itself. Its `intro:` reaches the view through the collection.
3. **The `raw` schema type.** `formFields` (`state/collection.ts`) draws a `raw` field as a text area holding the value rendered as one-line YAML flow (`renderFlowMap` of `server/entry-edit.ts` is server side; the client renders it as JSON text), and a save writes it back only when the text parses as a map of scalars, else the form refuses with `collection.form_raw_invalid`; if that is more than the package can carry, the field is left out of the form with the limitation reported, and the decision is the worker's to state.
4. **The pure parts.** `state/datasets.ts`: `accessSummary(datasets)`, `accessTone(access)`, `themeFacets(datasets, labels)`, `applyThemeFacets`, `datasetSearch`, `recoveryCommand(key)` (the argv the server builds, tested once here and once server-side); a `DataState` parsed from the instance state (search words, facets off).
