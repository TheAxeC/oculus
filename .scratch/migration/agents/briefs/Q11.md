## Decisions taken in this brief (each reversible, none silent)

1. The chat is an interactive `claude` terminal, so a conversation continues in the terminal itself; no `--session-id` bookkeeping and no chat box.
2. The portfolio index is a file under `~/.oculus/chat/` named by the terminal id, written at start, not deleted (the folder is the reader's to clear; the report says its size for the real hub).
3. The instruction and the focus note are catalog text, ported verbatim from the cockpit's INSTR, so Axel can edit them without a code change.
4. The Chat entry sits in the Update tray, not the rail's foot.
