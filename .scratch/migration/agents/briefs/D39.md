## What to build

When the step is done, a reader in a hub YAML file presses Cmd on a value that names a hub key and lands on the entry, lists every place that names a key in the References view, and renames a key everywhere through a Refactor Preview that writes nothing until Apply. Every reference is one a schema declares; nothing is found by matching text.

1. **The reference index** (Z725 C2, C7; G66). A new folder `src/lib/data/snapshot/references/` (Layer 1, data; `data/snapshot` goes from 8 to 9 items) builds, in the snapshot build, one index of every reference and every definition:
   - A reference is each value of a field whose `from` names a source, at the range of its scalar (inside the quotes of a quoted scalar), with the file's root key and path and the source and key it names. The fields are read from the schemas themselves: each hub data file's `schema:` (with `fieldsOf`, nested `records` fields included), the manifest schema (`manifestFields`, dotted names such as `status.chips` as nested keys), the side-project schema, the options catalog's entries with `from: domains` or `from: clusters` (`behavior.yml`'s `data_domains` and `slurm.resource`, `clusters` meaning the resources of kind `cluster`), the options catalog's entries whose `from` names a vocabulary list (`project_types`, `status_chips`, `entry_statuses`, `slide_tags`: `options.yml:196, 1054, 1070, 1113, 1137`, read through `data/sources/config/catalog/options.ts:430-435` from `type_color`, `status_legend` and `status_palette` of `vocab.yml`), so Find References on `manuscript` lists `config/sources.yml`'s scan `type` (Z735), the deck schema's `slides` (Z730 O2), and the `waiting-on` row once item 6 gives it a `from`. A `{ field, sources }` `from` takes the source the record's other field picks. ## Conventions

- A source file at most 880 lines and a component at most 520; at most ten tracked items in a folder; `relay.ts`, `transport.ts` and `state/client/context.ts` are split by concern when the step passes the line.

- A key, a value or a path from the hub that reaches HTML goes through the sanitiser or is text (G5).
- One line per paragraph or bullet in the Markdown and YAML the step edits.
