   - `categories` merges by `key`: a row naming oculus's key replaces it in place, a row with a new key comes after oculus's rows, `{ key: <key>, removed: true }` removes one.

   - A `null` or a removal naming a word or key oculus does not hold, two rows of the hub naming one key, and a value of the wrong kind (a list for a map key, a map for a list key) are findings naming the hub's `.oculus/config.yml` and the dotted key, and oculus's value stands for that word or key.
