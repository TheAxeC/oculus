The builder handed back with the cases' first run and a rule clash: brief item 1's "the Graphviz instance is loaded once per page and shared by every Map pane", built as two module-level variables in `layout.ts` (`:24-25`, `grep -n "^let" layout.ts`), breaks the spec's no-globals rule and `tests/checks/tree/boundaries.test.ts` "holds no process-wide state under src". The spec governs the brief, and a shape exists that meets both, so this is ruled here.

1. **The shared instance: (a).** `layout.ts` exports `createGraphviz()`, a factory that keeps the promise and the loaded instance inside the function it returns. `src/lib/state/client/context.ts` adds `graphviz` to the `ClientState` type (`:96`) and `graphviz: createGraphviz()` to what `createClientState` returns, and `Graph.svelte` reads it through `useState()`. The paths widen to `src/lib/state/client/context.ts` (the import, the type field and the one line in `createClientState`; nothing else in that file). The tests may preload the client's loader so the server-rendered Map tests keep seeing placed nodes. The lazy option was (b), one instance per pane, which leaves "shared by every Map pane" unmet. Exempting `layout.ts` in the boundaries check is not allowed.
2. **`Graph.svelte` under 540 lines** (`tests/checks/tree/size.test.ts`), by moving the load and any placement plumbing into `layout.ts` or the client state; no rule of the size check is changed.
3. **`seededRandom` and `Rng` go.** The brief listed `seededRandom` among what stays, but after the search is removed it has no caller in `src`, `tests` or `bin` (`grep -rn "seededRandom" src tests bin` prints only its definition at `graph.ts:410`), and `Rng` is used only by it (`grep -rn "\bRng\b" src tests`). Remove both, and say so in the report and the head comment of `graph.ts` where it lists what the file holds.
4. **Verify item 2** is replaced by two greps, since `settle(` matches 32 unrelated files: `grep -rn "optimize\|bestLayout\|placeInit\|isPhysics\|tunedFor\|ontuned\|seededRandom" src tests` prints nothing, and `grep -rn "settle(" src/lib/state/boards/structure src/lib/views/structure tests/state/boards/structure tests/views/structure` prints nothing.
