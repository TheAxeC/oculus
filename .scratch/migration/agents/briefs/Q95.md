The Settings view's Rail section draws each row of the rail list with a mark: the row's glyph drawn by `Glyph`. `Glyph` throws for a name the glyph vocabulary does not hold, and the empty string is such a name. "Add a button" appends a row whose glyph is empty, so the section throws, the new row is never drawn, and since the list being typed is kept in the tab's state, which the browser stores, every reload throws again and the whole page stays down. The fix: the mark draws the glyph only when the vocabulary holds it, and draws nothing otherwise. The rest of the row, the rule's messages and Save and Revert are unchanged.
