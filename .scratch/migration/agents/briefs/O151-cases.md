# O151, round 0: the rulings on the first run's hand-back

The builder resumes the build with these rulings. They change item 1's rule and settle three points the first run raised; everything else in the brief stands.

1. **Item 1's rule on other projects (Reading B).** A deck names no other project as such: no cross-reference, no "see also", no comparison with a sibling paper or another project's result, and no deck frames its project through a student project. A method, model or paper that the project's own manuscript or manifest names as what it builds on, applies, extends, proves a theorem about or compiles is named as those sources state it, since it is part of what the project is: the thesis deck names its four papers and their methods; a deck on a project that applies BTTR, HCCNet, BT-FNO, BTTN or COVERT names that model as its own sources do. The decks of `covert-theory` and `covert-applied` still never name or describe each other, and covert-theory's deck uses the name COVERT only where its own manuscript does. The current covert-applied comparison with HCCNet-FL (`covert-applied/present/main.md:48`) is the kind of line the rule removes. C4 stays as written; its reading checks that neither covert deck describes the other paper. Reading A, which drops what these projects build on, was the cheaper option and is not taken.
2. **No second slide of `kind: equation`.** A second slide is a `project` slide with `panels` or a `columns` slide with a heading. The project's gate counts only a front-matter `equation:` against the drawn ones (`integrity.test.ts:75-85`, `:109-115`, `:252`), so an `equation` slide would turn C6 red.
3. **The dot under a rice theme.** The dot is `0.75em` of the strip's value size: 9 px at the design size times the text scale, and 8.25 px under `body.rice`, following its 12/13 rule as every slide size does. Decision 5 holds at the design size; the report lists the rice value as a decision that can be reversed.
4. **C10's short labels.** A one-word tag text or spec label that names a kind of thing (such as "Measured" or "Cohort") counts as a fact true of each deck it stands in, and is listed in the report with the decks; a sentence, a hook, a headline, an equation of another project's model written as its own and a body heading block are never repeated across decks.
5. **C6's time limit.** `integrity.test.ts` is outside the paths and is not changed. The report gives the time of the row "reads a deck out of every project that has a present/ folder, with no finding" on each run, and the load average beside it.
