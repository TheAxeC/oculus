## Axel's ruling (plan.md, U1 and its Step 0)

Every glyph is drawn as its line icon everywhere: a text carrying a glyph draws the icon inline, the sparkline is drawn as SVG bars, a mark badge's hover says its meaning in words, and `glyphs.yml` loses its unicode column, keeping each name with its ASCII stand-in for the terminal themes, so a name with no icon is an error rather than a character.

## What to build

1. `config/catalogs/glyphs.yml` becomes one map, `glyphs:`, of name to ASCII stand-in; the `ascii:` map and every unicode character go. Every name has a stand-in, an ASCII string. The readers and the checks follow the new shape; a name with no icon in `icons.yml` is reported as a finding and fails a test, and is never drawn as text in the icon mode.
2. `Glyph.svelte` draws the icon in the icon mode and the stand-in in the ASCII mode, nothing else. `glyph(name)` answers the stand-in only, for the ASCII mode and for words; no caller puts a unicode glyph into text.
3. The token mechanism goes: no string of `config/` carries a glyph. Each of the 28 is replaced by its component drawing a `Glyph` beside the words (the theme menu's entries, the Update tray's note, the source error line, the radar intro, the HPC pill, the three Focus lanes). The words themselves stay; where a string carried the glyph inline in HTML (`radar.yml:12`), the icon is drawn beside the HTML, not inside it.
4. The sparkline is drawn as SVG bars in the text colour, one bar per count, the same heights the block ramp gave.
5. A mark badge's hover words say what the mark means, from the catalog, never a character.
6. The ASCII gate's exception for `glyphs.yml` (`! -name glyphs.yml` in the verification command, and any equivalent in the checks) goes, since the file is ASCII now: `LC_ALL=C grep -c '[^ -~]' config/catalogs/glyphs.yml` prints 0. Any other place that exempts glyph characters from an ASCII rule is closed the same way.
7. Tests for each, each red under its revert: a name without an icon fails; the theme menu draws an icon and no character; each of the other token sites draws an icon; the sparkline draws SVG bars; a mark badge's hover is words; the ASCII mode draws the stand-ins. A browser case over the Settings theme menu and the Focus lanes finds no character outside printable ASCII in their text (read with `textContent`), red under its revert.

## Decisions taken in this brief (each reversible, none silent)

1. `glyphs:` keeps its name and becomes name to ASCII stand-in, so every reader keeps its key; `ascii:` goes.
2. A name shared by several glyphs keeps its own stand-in; where two names had one character, each keeps the stand-in that character had.
