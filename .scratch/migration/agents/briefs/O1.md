# Brief: O1, the oculus scaffold

Read `../spec.md` first; it governs this package unchanged. Then `tools/oculus/DESIGN.md` in full: the sections "Repository layout", "Configuration", "Hot reload", "Conventions" and "Decisions taken" are what this package puts on disk.

## What to build

The empty application, with its toolchain, its configuration resolution and its first test, and nothing visual. Under `tools/oculus/`:

- A SvelteKit project: Svelte 5, TypeScript, Vite, Vitest, the Node adapter (`@sveltejs/adapter-node`), `ssr = false` on the one route. Create it non-interactively with the Svelte CLI (`npx sv create`; read `npx sv create --help` first and report the exact command used). No add-ons beyond Vitest. The package manager is npm; `node` and `npm` are on PATH (Node 23).
- `package.json` scripts, exactly these names: `dev`, `build`, `preview`, `check` (svelte-check), `test` (vitest run). The ledger's verification commands are `npm test`, `npm run check`, `npm run build`.
- `src/routes/+page.svelte`: renders one line of text from `config/text.yml` through `t("app.title")`, nothing else. `src/routes/+layout.ts` with `export const ssr = false`.
- `src/lib/state/text.ts`: `t(key: string, ...args: (string | number)[]): string` reading `config/text.yml` (a nested map flattened to dotted keys, `{0}` and `{1}` interpolation); a missing key throws with the key in the message. `config/text.yml` with the single key `app.title: oculus`. The server reads the catalog per request (one small file; O6's watcher replaces this with an in-memory copy pushed on change) and ships it to the client as JSON through the page's data, so editing `text.yml` and reloading the browser shows the change; the browser never reads the YAML as a file.
- `src/lib/data/sources/config.ts`: `loadLocal(engineDir)` resolving `local.yml` at `tools/oculus/local.yml`, keys `hub` (absolute path of the research hub) and `port` (integer), with derived defaults: `hub` is two directories above `tools/oculus` (resolved from the module's own location), `port` is 8790. An unknown key is reported once on stderr and ignored. A missing file means the defaults. Nothing reads an environment variable.
- `src/server.ts`: the Node entry that imports the adapter's handler and serves it on the resolved port, bound to 127.0.0.1. No WebSocket yet; the file exists so O6 attaches one.
- `tests/boundaries.test.ts`: walks every `.ts`, `.svelte.ts` and `.svelte` file under `src/lib`, extracts its `import` specifiers, and asserts the table in `DESIGN.md` "Boundaries" (ui imports nothing from state except `state/text`, views, shell or server; shell imports no file under views by name and nothing from server; views import nothing from shell, server or other views; state imports nothing from server or layer 3; data and server import nothing client-side). Implement it with `node:fs` and a regular expression over import lines; no new dependency. It passes on the scaffold because the folders are empty or hold only what this brief names, and it must fail if a fixture in a temporary directory violates a row: include one such negative case in the test.
- `tests/config.test.ts`: `loadLocal` with no file, with both keys, with an unknown key, in a temporary directory.
- `tools/oculus/.gitignore`: `node_modules/`, `.svelte-kit/`, `build/`, `local.yml`.
- `tools/oculus/README.md`: how to install, run `npm run dev`, run the three verification commands, and where `local.yml` lives; ten lines is enough.
- The empty folders the design names are NOT created; a folder appears when its first file does.

Dependencies allowed: what `sv create` installs, `@sveltejs/adapter-node`, `yaml` (for `config.ts` and `text.ts`), and nothing else. `npm install` is run once, by you, and `package-lock.json` is committed.

## Decisions this package bakes in, recorded by the orchestrator in DESIGN.md

- `local.yml` keys `hub` and `port`; default port 8790 (8787 is the cockpit, and must never be used).
- The verification commands `npm test`, `npm run check`, `npm run build`.
- The text catalog reaches the browser as page data at load and by socket push afterwards (from O6), never as a file the browser fetches.

## Conventions

Every file under 1000 lines (`sv create` output is small). ASCII in every file you author. One continuous line per paragraph or bullet in Markdown and YAML. No literal user-facing string in a component: the page's one line comes from `t()`. The `config/` folder holds `text.yml` only for now; the other six config files arrive with O5.
