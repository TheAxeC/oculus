## What to build

1. **Every file row opens its file to read.** Each row of the Catalogs, Schemas and Texts groups draws a read-only open, a `compact` `ToolButton` with the glyph `open_preview` that opens the row's file through `:oculus` in a source tab that cannot save, by the same `showDefaults` function the heading lines call. Its words are new keys under `settings.` in `workbench.yml`: the label `Show File` and the tip `Open oculus's {0} in a tab that only reads it`, `{0}` the row's path, true of every file of the three folders (decision 1). The heading lines keep Show Defaults and its words. The read-only open is drawn in every case: in the installed app, in the dev server, and whether or not a workspace folder holds oculus's `config/` folder.
2. **The edit open where the file can be edited.** Where `openTarget(OCULUS_CONFIG_ROOT, row.file)` gives a target, the row also draws the "Open file" button it draws today, after Show Defaults, opening the file through the workspace folder that holds it.
3. **No dead row.** The span `workbench.settings_open_unavailable` is no longer drawn, its key is removed from `workbench.yml`, and its CSS rule `.unavailable` (`List.svelte:248-251`) goes with it.
4. **Where the values are set** (ruling 757 names the Catalogs and Texts rows; the Schemas rows are not part of it). Each Catalogs row and the Texts group say where the values of their files are set, in plain words naming the file and the key:
   - the six catalogs other than vocab: in the open workspace file's `settings:`, under the key that catalog takes (`agents`, `patterns`, `glyphs`, `icons`, `latex_editing`, `latex_unimath`), said in each one's `desc_*` sentence;
   - `catalogs/vocab.yml`: its `desc_vocab` already says the hub's `.oculus/config.yml` and the registry files, and stays as it is unless a word of it is false;
   - the Texts group: `texts_about` says a workspace lays its own words over these in its workspace file's `settings:` under `text`.
   Each sentence is true of every place the key is drawn (a heading's file line and the Catalogs row both read `desc_*`).
5. **Comments.** The head comments of `List.svelte`, `groups.ts`, `config-files.ts` (`openTarget`'s doc comment), `scopes/rows.ts` and the `FileRow` comment of `view/folders.ts` say what a file row draws now, and lose any sentence the change makes false.

No other file changes than those under "Paths this step writes". `docs/HELP.md` is not changed (`agents/spec.md:72`); a sentence there that the change makes false is named in the report.
