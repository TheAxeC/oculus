### B. `data/guards.ts`

One module for the four type guards that fifteen files re-declare today. Exports, with these exact contracts:

- `isMap(value: unknown): value is Record<string, unknown>`: an object that is not null and not an array.
- `str(value: unknown): string | undefined`: the value when it is a string, else undefined. It does not trim and does not accept numbers.
- `text(value: unknown, fallback = ''): string`: `str(value) ?? fallback`.
- `strings(value: unknown): string[]`: the string items of an array, else `[]`.

The boundary rows: `state` may import `data/guards` beside `data/model` (`ALLOWED.state` in the test, the row in `DESIGN.md`); `ui/`, `shell/` and `themes/` may not. Replace the local declarations at these sites where the local contract is the same as the shared one, and keep a local one with a one-line comment naming the difference where it is not (`normalise.ts` line 72's `str` and `deposit.ts` line 170's `textOf` are the two to read closely; `server/hooks.ts` line 49's `str(body, key)` and `state/socket.svelte.ts` line 153's `strings` have different signatures and stay): `data/index.ts` 31, `data/normalise.ts` 67 and 82, `data/validate.ts` 62, `data/sources/feeds.ts` 29 and 33, `server/deposit.ts` 170, `server/git-routes.ts` 77, `server/project-files.ts` 87, `server/sessions/json.ts` 53 (already exported; its importers may switch to the guard or stay, say which), `state/board.ts` 256 to 264, `state/career.ts` 32 and 36, `state/collection.ts` 105, `state/feeds.ts` 39, `state/focus.ts` 189 and 193, `state/schema.ts` 56. `tests/data/guards.test.ts` covers the four with the edge cases (null, an array, a number, an empty string).
