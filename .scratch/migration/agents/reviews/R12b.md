## The html-sites audit

`LIB` is `src/lib` and `svelteFiles` recurses (`tests/html-sites.test.ts:35-44`), so **a site under `src/lib/shell` is covered**; so is every other folder under `src/lib`.

**A multi-line tag is handled.** `introTags` scans character by character from `<Intro` to the first `>` at brace depth 0, tracking `"`, `'` and backtick, so a newline inside the tag, a `>` inside an attribute string and a `>` inside a template literal all behave.

**`trusted={true}` is handled**: `isTrusted` is `/(^|\s)trusted(\s|$|=\{true\})/`.

**Four ways it can miss a trusted site:**
1. `trusted={someExpression}`, `trusted={!hidden}`, or `trusted={ true }` with spaces: `isTrusted` returns false, `looseTrustedIntros` skips the tag, and the raw `{@html}` at `Intro.svelte:34` is reached with nothing checking the words. This is the most likely of the four to happen by accident.
2. **Intro imported under another name.** `import Note from '$lib/views/shared/Intro.svelte'` then `<Note trusted html={...} />` is invisible to `matchAll(/<Intro(?=[\s/>])/g)`. Nothing in the audit resolves imports.
3. `<Intro {...props} />` where `props` carries `trusted`: skipped.
4. A tag carrying both `lines={...}` and `html={...}`: `attributeOf(tag, 'html') ?? attributeOf(tag, 'lines')` checks only `html`, so a loose `lines` beside a literal `html` passes.

Fix for 1 and 3 without much work: treat any occurrence of `trusted` in the tag as trusted (so `trusted={x}` is flagged rather than skipped), and check both attributes rather than the first present. Fix for 2 needs the audit to find the import alias per file, which is more than the shape it has.

**It does not pass vacuously.** `looseTrustedIntros` returning `[]` with no trusted site at all is guarded by "finds the trusted Intro sites there are, so the check above is not vacuous", asserting at least three trusted tags. One gap in that guard: it re-spells the trusted regex inline instead of calling the exported helper, so it proves `introTags` still finds tags and that `trusted` is still on three of them, but it would not notice if `isTrusted` (the private one that `looseTrustedIntros` actually uses) were broken to return false. Exporting `isTrusted` and using it in the guard would close that, at the cost of the independence the duplication buys.

The `ALLOWED` pair for `drawn(html)` and `drawn(line)` is now backed by the per-site check rather than standing alone, and its reason text says so. That is sound as far as the four holes above allow.
