### 3. The audit: hole, and how to close it

It does match the brief's counting command in every other respect: same id families, same `(^|[^A-Za-z])...([^A-Za-z0-9]|$)` boundaries, same session phrases, same four comment forms (`//`, `/*`, `<!--`, a line starting `*`), `src`/`tests`/`bin`, self-excepted by the content marker `oculus-plan-id-audit` rather than by name, printing `file:line: text` for every hit. The date pattern `[0-9]{4}-[0-9]{2}-[0-9]{2}` is strictly wider than the brief's `2026-..`, which the report discloses. Vitest prints the whole failure string (no truncation configured), and it would catch the worker's probe: `in O7 on` matches the `O[0-9]{1,2}[a-g]?` family with its boundaries.

The hole is the one the orchestrator asked about, and it is not hypothetical here:

- **An HTML comment split over lines**: `src/lib/ui/Tooltip.svelte:180-182` opens with `<!--` and its second and third lines carry no marker. Invisible.
- **A CSS or JS `/* */` block whose continuation lines do not start with `*`**: `src/lib/ui/Tooltip.svelte:219`, `src/lib/ui/Pane.svelte:53`, `src/lib/ui/Sash.svelte:112` and many more. Invisible, and this is where the `+layout.svelte` violation sits.
- **A JSDoc continuation line without a leading star**: same class, nothing normalises it (Prettier does not reformat comment interiors).
- A comment inside a template string is *not* an escape route: it still contains `//`, so it is caught.

Measured count of comment lines the audit cannot see, over `src tests bin`: **155**.

Fix, inside `hits()`, keeping `isComment` as it is:

```ts
let open = false;
source.split('\n').forEach((line, index) => {
    const inside = open;
    if (open && (line.includes('*/') || line.includes('-->'))) open = false;
    else if (!open && (line.includes('/*') || line.includes('<!--')) && !line.includes('*/') && !line.includes('-->')) open = true;
    if ((inside || isComment(line)) && HISTORY.test(line)) found.push(...);
});
```

With that in place the audit fails today on `+layout.svelte:17`, which is the proof it exercises the hazard.
