## Judgment calls

1. **Reader location.** The shared reader is `src/lib/data/helpers/files/latex.ts`, not `data/helpers/latex/`: `data/helpers/` holds 10 items (`ls src/lib/data/helpers | wc -l` prints 10), the folder limit. `tests/checks/tree/boundaries.test.ts` allows `data/helpers/files/latex` in the `state` row because `state/sources/explorer/sections/outline.ts` imports it.
2. **Other folders for the same limit.** The view's rows are in `src/lib/views/shared/latex/` (`views/academic/latex/` holds only the view); the terminal target type is in `state/sessions/terminal/latex-target.ts`; the server's parts are in `server/content/latex/` beside `content/latex.ts`.
3. **The dependency has optional dependencies.** The brief says `latex-utensils` has no runtime dependency; `package-lock.json` lists `optionalDependencies` `commander` `^11.0.0` and `pegjs-backtrace` `^0.2.1` for 7.0.0. Nothing here imports them. No other dependency was added.
4. **KaTeX options.** The hover widget sets `throwOnError: false` and `trust: false` itself, as `views/academic/present/markup.ts` does for the slides; they are not shared because `ui/` may not import from `views/`.
5. **Build on save lives in the save function of the source store.** `Source.svelte` is at 509 of 540 lines, and the brief puts the call in `Source.svelte`. The call is in `state/sessions/source.svelte.ts` (`createSource(..., saved)`, wired in `state/client/context.ts`), so a save from any caller builds, and a failed save calls nothing (`tests/state/sessions/source.test.ts`).
6. **Format Document and markers reach the editor through `latex-editor.ts`** (`views/sources/source/`), which builds the `extension` object from the client; `ui/controls/editor/Editor.svelte` takes only that object, so `ui/` imports nothing of the state. `views/sources/source/Editor.svelte` and `ui/controls/editor/types.ts` changed for it.
7. **Quoting in the build command.** `shellWord` always quotes, so the command reads `latexmk -pdfxe ... 'main.tex'`; case 5 writes `m.tex` unquoted. The tests assert the quoted form.
8. **Statuses.** Item 14 says 404 for a main that is not a main of the folder, and the `/api/latex` parameters answer 404. The terminal `latex` action answers 400 for its refusals, as case 6 says.
9. **Test placement.** `latex-editor.test.ts` is in `tests/views/academic/` because `tests/views/sources` holds 10 items. The store test is a folder `tests/state/sessions/latex/` with two files for the 900-line limit.
10. **Outline state is held by the store.** The outline of a main is a query-layer entry `['latex-outline', ...target, main]`, separate from `['latex', ...]` so `latexDiagnostics()` scans only states. It is asked when the disclosure opens, asked again when a new build of the main changed its log, and dropped on `invalidate`; a late answer after the view closed changes nothing.
11. **Glyph of the view.** The tab glyph is `publish` (`config/text/views/academic/latex.yml`, `latex_glyph`). `tests/state/workbench/navigation/registry.test.ts` requires every non-collection view to carry a glyph of its own, and `section`, the first choice, is Slides' (`slides_glyph: section` in `config/text/views/academic/slides.yml`). This is a user-visible choice; changing it is one key.
12. **The view asks the box for the tint** (`<Pane {title} tinted>`), as `tests/views/whole/tinted.test.ts` requires of a view that draws no surface of its own.
13. **Problems list.** The project panel's disclosure counted and listed errors only; the shared rows count errors plus warnings and list errors first, then warnings (item 5 of the brief). The number in the disclosure is larger than before for a project with warnings.
14. **No allow-list entries were added** to `tests/checks/**`; the absence assertions and view audits carry reason comments. `tests/checks/tree/allow-duplication.txt` needed no change.
15. **Scratchpad.** At one point this step copied its tree over the orchestrator's shared `scratchpad/base`; that copy was overwritten and this step now keeps its own copies under `scratchpad/d14/`. Anything that reads `scratchpad/base` should be checked.
