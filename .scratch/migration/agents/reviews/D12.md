## Security

The pattern never reaches a shell and cannot become an option: `search.ts:60-84` is the one call site, `execFile(rgPath, args, { cwd, encoding, timeout, maxBuffer })`; the vector is built once in `data/search.ts:84-92` and the only request-derived member is `query.q`, pushed as the value of `--regexp`, the path after it the constant `.`; checked against the dependency's binary with `-foo`, `--files`, `--` and `-e` as patterns, each taken as the pattern; pinned at `tests/data/search.test.ts:102-104`. The root is always a served root and the working directory that root's own: `rootsOf` filters the list by key, a key not on it refused before any process (asserted with a call counter); the route composes the list from the server context. No path and no line leaves the root: no `--follow`, and over a temporary folder holding a symlink to an outside file and an outside directory neither was followed; `pathIn` strips only `./`; a hit opens through `openSourceFile`, whose route refuses anything outside after realpath. Dotfiles and hidden directories are not searched either (a `.env` and a `.hidden/x.txt` holding the pattern were skipped), good for secrets, unsaid in HELP.md. Gates: `sameOrigin` then `hasToken` before the query is read, asserted with a process counter; the token on a GET is right, since `auth.ts:39` accepts `sec-fetch-site: none` (a typed address) and without the token anyone who could load the URL would get every matching line back. Timeout and caps: per root, enforced by `execFile`'s own timeout and by `within()`; `--max-filesize 2M` and the three globs asserted word for word; `.gitignore` honoured; the binary `rgPath` from `@vscode/ripgrep`, resolved with no install-time download, kept as an external import in the built server.

**The cost the caps do not bound.** Measured: `q=e` over `tools/oculus` alone produces 40,306,017 bytes of ripgrep JSON in 0.05 s; one `runSearch` over that root took 223 ms and moved the heap from 9.1 MB to 178.3 MB to return 500 hits, repeated per root sequentially over `all` (four fixed roots plus the workspace's), with no total-request bound. A reader triggers it with one letter and Enter. `spawn` with a line-wise stream and a kill at the cap would bound both.
