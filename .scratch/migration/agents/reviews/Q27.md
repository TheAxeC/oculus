In Chrome, Ctrl+Tab and Ctrl+Shift+Tab are reserved browser accelerators: the page receives the keydown, but cancelling it does not stop Chrome switching its own tab, and that holds for Chrome on macOS, where those two chords cycle Chrome's tabs. **I did not measure this**; I am stating known Chrome behaviour, not a run in this worktree. `DESIGN.md:309` ("Still undecided, the native window") records that oculus runs in a browser tab today, so the decision line overstates what the code achieves in the form oculus is used in now.
