## Verification, every package

A check run by hand is read by its own exit (`npm run lint > out.txt 2>&1; echo $?`), never through a pipe into `tail`, whose exit is the pipe's; the landing script reads each step's own status. When the script stops on the git watcher's timing case, the file alone is the second measurement and the remaining steps run by hand in the script's order.

This ledger holds `land.sh` (the `plan-orchestration` skill's `templates/land.sh` with its three `ADAPT` edits made; the skill's section "The landing script" describes it): a landing runs from the repository root as `sh tools/oculus/.scratch/migration/land.sh <package> <base> <runs directory>`. The script makes the worktree wip commit, brings the package onto main's head as `<package>-land`, stages it on main, runs the oculus checks below in order and prints the diff stat, the usage rows in the format of the Usage section and the staged paths for the booking; `--no-browser` only when the browser check is deferred on purpose; a worktree conflict prints its paths and exits 2 with the worktree left on `<package>-land`; an occupied port 8792 exits 3; the script stops before the package commit, the plan tick and the state rewrite, which stay the orchestrator's. `sh tools/oculus/.scratch/migration/land.test.sh` proves it on a scratch repository.

Until O1 lands there is no oculus toolchain; the cockpit's commands are the gate for the C packages.
- Cockpit packages (any bug fix on the frozen cockpit): `cd tools/cockpit && python3 build.py --selftest && python3 build.py --dummy && bash tests/run.sh`, all from `tools/cockpit`, then once from the hub root: `python3 tools/cockpit/build.py --selftest`.
- Oculus packages, from O1 on, run from `tools/oculus`: `npm test` (Vitest: boundaries, contrast, keys, integrity, per-source and per-server tests), `npm run check` (svelte-check), `npm run build` (the Node adapter build must complete), and from Q1 (2026-09-11) `npm run lint` (ESLint flat config, exit 0 with no output); from Q2 (2026-09-11) the orchestrator also runs `npm run build && npm run test:browser` at every landing (Playwright on the installed Chrome over a copy of `demo/`, 18 specs, about 25 s).
