# The demo hub

A synthetic research hub: eleven projects in six folders (ideas, active, manuscripts, software, coauthor, archive), each carrying its own `tier` and `type`, the five registries they point into, the eight collection files, the feeds and the career file. Nothing in it is real, so it is safe to serve, to write to and to copy as the starting point for a hub of your own. Add this folder to the open workspace (Add Folder) and, as it holds `.oculus/config/`, oculus serves it as a hub; make it the workspace's `primary` and its records are the bare ids. A run that must leave the checkout's own configuration alone copies `config/` somewhere else and starts the server with `--engine <that directory>`.

The Present view has two decks over this folder: the portfolio deck `deck/` (a title slide, a group that finds every project's `present/` folder and a closing slide, 5 slides with the summary) and the project deck `projects/active/graph-bandits/present/` (a `present.yml` and a `main.md` of `kind: project`). The reader finds one thing to say about it: `graph-bandits` names the domain `graphs`, which `config/catalogs/vocab.yml` does not list, so its slides are drawn in the neutral tone.
