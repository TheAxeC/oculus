# graph-bandits

Bandit algorithms that choose which node to probe next on a graph that keeps changing.

## Results
- Cumulative regret 0.42 vs 0.61 for the static-graph baseline (synthgraph, 20 seeds).

## Data
- `synthgraph` - synthetic evolving-graph benchmark (open).
- `stream-bench` - streaming benchmark for the online setting (registration).
