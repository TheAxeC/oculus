# demo-toolkit

The reference implementation of the graph-transfer method, released as an installable library rather than written up as a paper of its own.

## What it is
A Python package with the transfer warm-start, the bandit sampler, and the two evaluation splits the papers report.

## Papers
- `graph-transfer`, the method this library implements.
- `graph-bandits`, the sampler added in 0.4.
